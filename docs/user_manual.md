## 1. 系统概述

### 1.1 系统简介

家具销售提成管理系统是一套面向家具销售企业的综合管理平台，涵盖商品管理、库存管理、订单管理、提成计算、工资发放等核心业务流程。系统由三个子项目组成：

| 子项目 | 技术栈 | 使用对象 | 访问方式 |
|--------|--------|----------|----------|
| 管理后台 | Vue 3 + Element Plus | 管理员、经理、财务 | PC 浏览器 |
| 员工APP | UniApp + Vue 3 | 销售员、仓库管理员 | 手机浏览器 / 微信小程序 |

## 2. 管理后台使用指南

### 2.1 登录

#### 访问地址

在浏览器中输入管理后台地址，例如：`https://admin.yourdomain.com`

#### 登录步骤

1. 在登录页面输入用户名和密码
2. 点击「登录」按钮
3. 登录成功后自动跳转到系统首页

> **首次登录：** 系统初始管理员账号为 `admin`，密码为 `123456`。首次登录后请立即修改密码。

#### 修改密码

1. 点击右上角用户头像
2. 选择「修改密码」
3. 输入旧密码和新密码
4. 点击「确认修改」

### 2.2 首页仪表盘

登录后默认进入首页仪表盘，展示以下核心数据：

- **销售概览：** 本月销售额、订单数、客户数，以及与上月的对比变化
- **回款情况：** 本月回款金额、回款率、待回款金额
- **待办事项：** 待审核订单、待审核回款、库存预警等
- **业绩排行：** 销售员业绩排行榜
- **最近订单：** 最新创建的订单列表

可通过顶部的时间筛选器切换查看今天、本周、本月或本年的数据。

### 2.3 用户管理

#### 查看用户列表

1. 在左侧菜单中点击「系统管理」 -> 「用户管理」
2. 系统展示用户列表，包含用户名、姓名、角色、门店、状态等信息
3. 可通过搜索框按用户名、姓名、手机号搜索
4. 可通过筛选条件按角色、状态过滤

#### 创建新用户

1. 点击列表上方的「新增用户」按钮
2. 在弹出的表单中填写以下信息：
   - **用户名：** 登录账号，必须唯一
   - **密码：** 初始密码，至少 6 位
   - **真实姓名：** 员工姓名
   - **手机号：** 联系电话
   - **角色：** 从下拉列表选择角色
   - **所属门店：** 从下拉列表选择门店
3. 点击「确定」完成创建

#### 编辑用户

1. 在用户列表中找到目标用户
2. 点击操作列的「编辑」按钮
3. 修改需要变更的信息
4. 点击「确定」保存

#### 重置密码

1. 在用户列表中找到目标用户
2. 点击操作列的「重置密码」按钮
3. 输入新密码
4. 点击「确定」完成重置

> **提示：** 建议通知用户重置密码后首次登录时自行修改密码。

#### 禁用/启用用户

1. 在用户列表中找到目标用户
2. 点击操作列的「禁用」或「启用」按钮
3. 禁用后该用户将无法登录系统

### 2.4 角色权限管理

#### 查看角色列表

1. 在左侧菜单中点击「系统管理」 -> 「角色管理」
2. 系统展示角色列表，包含角色名称、描述、关联用户数等信息

#### 创建角色

1. 点击「新增角色」按钮
2. 填写角色信息：
   - **角色标识：** 英文标识，如 `store_manager`
   - **角色名称：** 显示名称，如「门店经理」
   - **角色描述：** 角色职责说明
   - **权限配置：** 勾选该角色拥有的权限
3. 点击「确定」完成创建

#### 编辑角色权限

1. 在角色列表中找到目标角色
2. 点击操作列的「编辑」按钮
3. 在权限树中勾选或取消权限
4. 点击「确定」保存

### 2.5 商品管理

#### 品类管理

**查看品类列表：**

1. 在左侧菜单中点击「商品管理」 -> 「品类管理」
2. 系统以树形结构展示品类层级关系

**创建品类：**

1. 点击「新增品类」按钮
2. 填写品类名称、选择父级品类（可选）、设置排序
3. 点击「确定」完成创建

#### 商品管理

**查看商品列表：**

1. 在左侧菜单中点击「商品管理」 -> 「商品列表」
2. 系统展示商品列表，包含商品图片、名称、编码、品类、价格、库存、状态等
3. 可通过搜索框按商品名称或编码搜索
4. 可通过筛选条件按品类、上下架状态过滤

**创建商品：**

1. 点击「新增商品」按钮
2. 在商品表单中填写以下信息：
   - **基本信息：** 商品名称、编码、所属品类、商品描述
   - **图片信息：** 上传商品主图和详情图片
   - **价格信息：** 销售价、成本价、提成比例
   - **SKU 信息：** 添加商品规格（如颜色、尺寸），每个规格可单独设置价格
3. 点击「确定」完成创建

**商品上下架：**

1. 在商品列表中找到目标商品
2. 点击操作列的「上架」或「下架」按钮
3. 下架后该商品将不在员工APP中展示

**编辑商品：**

1. 在商品列表中找到目标商品
2. 点击操作列的「编辑」按钮
3. 修改商品信息
4. 点击「确定」保存

### 2.6 库存管理

#### 库存查询

1. 在左侧菜单中点击「库存管理」 -> 「库存查询」
2. 系统展示各仓库的商品库存信息
3. 可按仓库、商品、SKU 编码筛选
4. 可勾选「仅显示低库存」查看库存预警商品

#### 库存预警

1. 在左侧菜单中点击「库存管理」 -> 「库存预警」
2. 系统展示所有低于安全库存的商品列表
3. 可对预警进行处理：
   - **创建采购单：** 一键生成采购单进行补货
   - **忽略：** 暂不处理该预警

#### 采购管理

**创建采购单：**

1. 在左侧菜单中点击「库存管理」 -> 「采购管理」
2. 点击「新建采购单」按钮
3. 填写采购信息：
   - **供应商：** 选择供应商
   - **入库仓库：** 选择入库仓库
   - **预计到货日期：** 设置预期到货时间
   - **采购明细：** 添加采购商品、SKU、数量、单价
4. 点击「保存草稿」或「提交审核」

**审核采购单：**

1. 在采购列表中找到待审核的采购单
2. 点击「审核」按钮
3. 查看采购明细，选择「通过」或「驳回」
4. 填写审核备注，点击「确定」

**确认入库：**

1. 采购单审核通过后，在列表中点击「入库」按钮
2. 核对实际到货数量，可修改入库数量
3. 点击「确认入库」，系统自动更新库存

#### 调拨管理

**创建调拨单：**

1. 在左侧菜单中点击「库存管理」 -> 「调拨管理」
2. 点击「新建调拨单」按钮
3. 填写调拨信息：
   - **调出仓库：** 选择调出仓库
   - **调入仓库：** 选择调入仓库
   - **调拨明细：** 添加调拨商品、SKU、数量
4. 点击「保存草稿」或「提交审核」

**调拨流程：**

```
创建调拨单 -> 提交审核 -> 审核通过 -> 确认出库（调出方） -> 确认入库（调入方） -> 完成
```

#### 仓库管理

1. 在左侧菜单中点击「库存管理」 -> 「仓库管理」
2. 可新增、编辑、删除仓库信息
3. 每个仓库可设置负责人和联系电话

#### 礼品管理

1. 在左侧菜单中点击「库存管理」 -> 「礼品管理」
2. 管理赠品信息，包括名称、编码、成本价、数量
3. 礼品可在创建订单时作为赠品添加

#### 供应商管理

1. 在左侧菜单中点击「库存管理」 -> 「供应商管理」
2. 管理供应商信息，包括名称、联系人、电话、地址、银行信息
3. 供应商信息在创建采购单时使用

### 2.7 订单管理

#### 创建订单

1. 在左侧菜单中点击「订单管理」 -> 「订单列表」
2. 点击「新建订单」按钮
3. 填写订单信息：
   - **客户信息：** 选择或新建客户
   - **门店：** 选择下单门店
   - **配送信息：** 配送地址、预计配送日期
   - **商品明细：** 添加商品、选择 SKU、设置数量和折扣
   - **赠品：** 可选择添加赠品
   - **备注：** 订单备注信息
4. 点击「保存草稿」或「提交审核」

#### 订单列表

1. 系统展示订单列表，包含订单号、客户、门店、销售员、金额、状态等
2. 可通过搜索框按订单号或客户名搜索
3. 可按状态、门店、销售员、日期范围筛选
4. 点击订单号可查看订单详情

#### 审核订单

1. 在订单列表中找到待审核的订单
2. 点击「审核」按钮
3. 查看订单详情，确认信息无误后选择「通过」或「驳回」
4. 填写审核备注，点击「确定」

#### 取消订单

1. 在订单列表中找到需要取消的订单
2. 点击「取消」按钮
3. 填写取消原因，点击「确定」
4. 系统将释放锁定的库存

#### 退货处理

1. 在订单列表中找到需要退货的订单
2. 点击「退货」按钮
3. 填写退货原因，选择退货商品和数量
4. 填写退款金额，点击「提交」
5. 退货审核通过后，系统自动回退库存和提成

#### 回款管理

**录入回款：**

1. 在左侧菜单中点击「订单管理」 -> 「回款管理」
2. 点击「录入回款」按钮
3. 填写回款信息：
   - **关联订单：** 选择订单
   - **回款金额：** 本次回款金额
   - **回款方式：** 现金、银行转账、微信、支付宝
   - **回款日期：** 实际回款日期
   - **参考号：** 银行流水号等
4. 点击「确定」提交

**审核回款：**

1. 在回款列表中找到待审核的回款记录
2. 点击「审核」按钮
3. 核对回款信息，选择「通过」或「驳回」
4. 回款审核通过后，系统自动计算对应提成

#### 客户管理

**查看客户列表：**

1. 在左侧菜单中点击「订单管理」 -> 「客户管理」
2. 系统展示客户列表，包含姓名、手机号、来源、跟进销售员、订单数、消费金额等
3. 可按来源、门店、销售员筛选

**创建客户：**

1. 点击「新增客户」按钮
2. 填写客户信息：姓名、手机号、性别、来源、跟进销售员等
3. 点击「确定」完成创建

**跟进记录：**

1. 在客户列表中点击客户姓名进入详情
2. 切换到「跟进记录」标签页
3. 点击「添加跟进」按钮
4. 填写跟进信息：
   - **跟进方式：** 电话、上门、微信、其他
   - **跟进内容：** 详细描述沟通内容
   - **跟进结果：** 有意向、待考虑、无意向、成交
   - **下次跟进日期：** 设置提醒时间
5. 点击「确定」保存

#### 同行管理

1. 在左侧菜单中点击「订单管理」 -> 「同行管理」
2. 记录同行竞争对手信息，包括名称、联系人、主营产品等
3. 便于销售员了解市场竞品情况

### 2.8 提成管理

#### 提成查询

1. 在左侧菜单中点击「提成管理」 -> 「提成列表」
2. 系统展示提成记录列表，包含员工、订单、类型、金额、状态等
3. 可按员工、订单、周期、类型、状态筛选
4. 点击「提成汇总」可查看按员工汇总的提成数据

#### 手工调整提成

1. 在提成列表中找到需要调整的记录
2. 点击「调整」按钮
3. 输入调整后金额和调整原因
4. 点击「确定」保存

> **注意：** 提成调整操作会记录操作日志，请确保调整原因明确合理。

#### 触发提成计算

1. 在左侧菜单中点击「提成管理」 -> 「提成计算」
2. 选择薪资周期（如 2026-05）
3. 可选择指定员工或全部员工
4. 点击「开始计算」按钮
5. 系统将根据已审核回款自动计算提成

#### 基金池管理

**创建基金池：**

1. 在左侧菜单中点击「提成管理」 -> 「基金池管理」
2. 点击「新建基金池」按钮
3. 填写基金池信息：
   - **名称：** 如「2026年5月销售基金池」
   - **周期：** 所属薪资周期
   - **总额：** 基金池总金额
   - **分配规则：** 平均分配或按业绩比例分配
   - **起止日期：** 基金池有效期间
4. 点击「确定」创建

**结算基金池：**

1. 在基金池列表中找到需要结算的基金池
2. 点击「结算」按钮
3. 查看各参与人的份额明细
4. 可手动调整份额或使用系统自动计算
5. 点击「确认结算」

#### 老带新管理

1. 在左侧菜单中点击「提成管理」 -> 「老带新管理」
2. 查看老带新记录列表
3. 可手动创建老带新关联记录
4. 系统将根据配置的提成比例自动计算老带新提成

### 2.9 工资管理

#### 生成工资

1. 在左侧菜单中点击「工资管理」 -> 「工资列表」
2. 点击「生成工资」按钮
3. 选择薪资周期
4. 可选择指定员工或全部员工
5. 点击「确认生成」
6. 系统将汇总基本工资、提成、奖金、扣款，生成工资单

#### 确认工资

1. 在工资列表中找到待确认的工资单
2. 点击「确认」按钮
3. 可调整奖金和扣款
4. 填写备注，点击「确认」

#### 发放工资

1. 在工资列表中找到已确认的工资单
2. 点击「发放」按钮
3. 选择发放方式（银行转账、现金）
4. 点击「确认发放」
5. 工资状态变更为「已发放」

### 2.10 数据分析

#### 仪表盘

1. 在左侧菜单中点击「数据分析」 -> 「仪表盘」
2. 查看核心业务指标和趋势图表
3. 可切换时间范围（今天、本周、本月、本年）

#### 销售报表

1. 在左侧菜单中点击「数据分析」 -> 「销售报表」
2. 可查看：
   - **销售总览：** 总销售额、订单数、客单价、毛利等
   - **销售趋势：** 按日/周/月展示销售趋势图
   - **业绩排行：** 销售员业绩排行榜
3. 可按门店、品类、日期范围筛选

#### 利润分析

1. 在左侧菜单中点击「数据分析」 -> 「利润分析」

## 4. 常见问题FAQ

### 4.1 登录相关

**Q: 忘记密码怎么办？**

A: 请联系系统管理员在管理后台为您重置密码。重置后使用新密码登录，建议首次登录后立即修改密码。

**Q: 登录提示"用户名或密码错误"？**

A: 请确认输入的用户名和密码是否正确，注意大小写。如果多次尝试仍失败，请联系管理员确认账号状态是否正常。

**Q: 登录后页面空白？**

A: 请尝试以下步骤：
1. 清除浏览器缓存后重新访问
2. 确认使用的是最新版 Chrome、Edge 或 Safari 浏览器
3. 如果使用微信小程序，请更新微信到最新版本
4. 如果问题持续，请联系技术支持

**Q: 提示"账号已被禁用"？**

A: 您的账号已被管理员禁用，请联系管理员了解原因并申请启用。

### 4.2 订单相关

**Q: 创建订单后可以修改吗？**

A: 草稿状态的订单可以修改。已提交审核的订单如需修改，请联系审核人驳回后重新编辑。

**Q: 订单审核被驳回怎么办？**

A: 在订单列表中找到被驳回的订单，查看驳回原因，修改后重新提交审核。

**Q: 如何取消订单？**

A: 在订单详情页点击「取消订单」按钮，填写取消原因后提交。注意：已发货或已完成的订单可能无法直接取消，请联系经理处理。

**Q: 订单中的赠品如何添加？**

A: 创建订单时，在商品明细下方有「添加赠品」入口，选择赠品和数量即可。

**Q: 客户退货后提成怎么处理？**

A: 退货审核通过后，系统会自动扣减对应的提成金额。如果提成已发放，将在下月工资中扣除。

### 4.3 提成相关

**Q: 提成是怎么计算的？**

A: 提成计算规则如下：
- **订单提成：** 按订单实际回款金额乘以提成比例计算
- **基金池提成：** 按基金池分配规则（平均分配或按业绩比例）计算
- **老带新提成：** 老员工按被推荐新员工的订单金额乘以老带新比例计算

**Q: 提成什么时候计算？**

A: 系统默认每月1日凌晨自动计算上月提成。也可由管理员手动触发计算。

**Q: 为什么我的提成金额和预期不一致？**

A: 可能的原因：
1. 回款尚未审核通过（只有审核通过的回款才计算提成）
2. 管理员对手工调整了提成
3. 订单存在退货扣减
请查看提成明细了解具体计算依据，如有疑问请联系财务或经理。

**Q: 提成多久发放一次？**

A: 提成随每月工资一起发放，具体发放日期由公司规定。

### 4.4 工资相关

**Q: 工资单什么时候生成？**

A: 工资单通常在每月初由财务或管理员生成，具体时间取决于公司规定。

**Q: 工资单中的数据可以修改吗？**

A: 草稿状态的工资单可以由管理员调整奖金和扣款。已确认或已发放的工资单不可修改。

**Q: 如何查看历史工资？**

A: 在管理后台「工资管理」或员工APP「个人中心」 -> 「我的工资」中查看。

### 4.5 库存相关

**Q: 什么是库存预警？**

A: 当某商品库存数量低于预设的安全库存阈值时，系统会自动生成库存预警，提醒及时补货。

**Q: 如何申请补货？**

A: 管理后台可在库存预警页面直接创建采购单。也可在「采购管理」中手动创建采购单。

**Q: 调拨需要多久完成？**

A: 调拨流程为：创建 -> 审核 -> 出库 -> 入库。具体时间取决于审核速度和物流时间。

### 4.6 移动端相关

**Q: 支持哪些手机系统？**

A: 员工APP支持以下方式访问：
- H5 网页：支持所有智能手机浏览器（iOS Safari、Android Chrome 等）
- 微信小程序：支持 iOS 和 Android 微信客户端
- APP（如已打包）：支持 iOS 12+ 和 Android 8.0+

**Q: 小程序搜索不到怎么办？**

A: 请确认小程序名称正确，或直接扫描小程序码进入。首次使用需要在微信中搜索并添加。

**Q: APP提示版本过低怎么办？**

A: 请更新到最新版本。H5 版本会自动更新，小程序版本需要在微信中下拉刷新，APP 版本需要在应用商店更新。

**Q: 离线可以使用吗？**

A: 目前系统需要网络连接才能使用。部分已缓存的数据可以离线查看，但创建订单、提交数据等操作需要联网。

### 4.7 其他问题

**Q: 系统支持数据导出吗？**

A: 管理后台的列表页面通常支持导出 Excel 功能，点击列表上方的「导出」按钮即可。

**Q: 如何联系技术支持？**

A: 可通过以下方式联系技术支持：
- 在管理后台「系统配置」 -> 「关于」中查看联系方式
- 在员工APP「个人中心」 -> 「关于」中查看联系方式
- 发送邮件至技术支持邮箱

**Q: 建议和反馈如何提交？**

A: 请联系系统管理员或通过技术支持渠道提交您的建议和反馈。
